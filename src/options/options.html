CleanThis · Settings

Download protection

Off by default. While it is on, the web address of a matching download is sent to cleanthis.io, which fetches and cleans the file and gives you the cleaned copy. You can always choose to download the original instead — nothing is ever blocked outright.

Flagged-site warnings

Off by default. While it is on, the extension keeps a local copy of cleanthis.io's flagged-site list and checks the addresses you visit on your device — they are never sent to cleanthis.io or anyone else, and no page is ever scanned automatically. A warned site is never blocked: you can always continue. Turning this on asks for the browser's "tabs" permission, which is what lets the extension see the address it checks — locally.

File types to clean automatically

Only ticked download types are intercepted. The list comes from what cleanthis.io supports, so new types appear here on their own.

Daily allowance

No requests yet.

cleanthis.io allows a set number of scans and files per day. The extension pauses rather than retrying when the allowance runs out.
