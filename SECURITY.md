# Security policy — CleanThis browser extension

## Reporting a vulnerability

**Please report privately, not as a public issue.** Use GitHub's private
vulnerability reporting on this repository: open the
[Security tab](../../security) and choose *Report a vulnerability*. That opens a
private thread visible only to the maintainers, so a problem can be fixed before
it is described in public.

Please don't open a normal issue, a pull request, or a discussion for a security
problem — those are public the moment you post them.

## What's in scope

This repository: the extension that ships to Chrome, Edge, Brave, Opera and
Firefox. Things worth reporting include anything that lets a webpage reach the
extension's privileged surfaces, causes the extension to act on a site it should
not, sends data anywhere other than cleanthis.io, or bypasses the flagged-site
warning.

Findings about the **cleanthis.io service itself** — the APIs, the website, the
scanning and cleaning that happen server-side — belong with that service rather
than here, but report them the same way and they'll be routed.

Out of scope: reports generated by automated scanners with no working example,
missing hardening headers with no exploitable consequence, and the deliberate
design limits already written down in [PRIVACY.md](PRIVACY.md) and the README
(the extension only ever talks to cleanthis.io; checks run on the top-level page
rather than inside frames).

## What to expect

The extension is a one-person beta project, so there is no paid bounty and no
committed response time. What you can expect is a genuine reply, credit in the
release notes if you'd like it, and a fix in a tagged release rather than a
quiet patch.

## Supported versions

Only the most recent release is supported. Older builds are not patched — the
extension does not auto-update while it is unpublished, so please install the
newest zip from [Releases](../../releases) before reporting.

## Verifying a build

Releases from v0.6.11-beta onward carry a `SHA256SUMS` file alongside the
two zips. Check the zip
you downloaded against it before installing:

```
sha256sum -c SHA256SUMS
```
